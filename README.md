# SemVID project website

Static project page for **Keeping the Evidence Chain: Semantic Evidence Allocation for Training-Free Token Pruning in Video Temporal Grounding**.

The site has no build step. Open `index.html` directly or run a local server:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

The `gh-pages` branch is published at <https://jiaqili404.github.io/SemVID/>.
